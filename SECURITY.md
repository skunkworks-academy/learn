# Security policy

Do not report suspected vulnerabilities in public issues.

Email `security@skunkworks.africa` with:

- affected repository and URL
- clear reproduction steps
- expected and observed behaviour
- impact assessment
- supporting screenshots or logs with secrets removed

Never include passwords, access tokens, learner data, private assessment content or lab credentials in a report.

Supported security concerns include access-control bypasses, exposed secrets, unsafe redirects, dependency vulnerabilities, cross-site scripting, insecure form handling and accidental publication of protected course content.
